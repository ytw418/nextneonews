- **CJK 줄바꿈:** 일본어 제목은 `word-break: auto-phrase`(Chrome 119+, 문절 단위 줄바꿈), 본문은 `line-break: strict` + `text-wrap: pretty`. 번체 제목은 BudouX 방식(`keep-all` + 구 경계에 `<wbr>`)으로 "登/上" 같은 어절 분리를 막음. 운영에서는 BudouX(ja·zh-hant 지원)를 서버에서 돌리면 Safari에서도 같은 결과가 납니다.
- **폰트:** Google Fonts 없음. ja `"Hiragino Sans","Hiragino Kaku Gothic ProN","Noto Sans JP","Yu Gothic",Meiryo` / 명조 `"Hiragino Mincho ProN","Yu Mincho","Noto Serif JP"` / zh-TW `"PingFang TC","Noto Sans TC","Microsoft JhengHei"`. 라틴 디스플레이 서체(Futura·DIN)는 Apple 기기에만 있으므로, 운영에서는 **라틴 글자만 서브셋한 웹폰트를 자체 도메인에서 서빙**(중국에서도 열림)하는 것을 전제로 합니다.
- **광고·제휴 표기:** 일본은 2023년 10월부터 스텔스 마케팅 규제(경품표시법)로 "PR/広告" 표기가 필요합니다. 모든 시안의 제휴 박스에 `PR` 라벨과 "링크 구매 시 수익 발생" 문구를 넣었습니다. AdSense 라벨은 정책상 허용되는 "広告 / Advertisement / 廣告"만 썼습니다.

**이 사업에 대한 장단점**
- 장점: 일본 독자에게 가장 익숙함(신뢰감). **광고 칸이 가장 많고** 목록형이라 노출(viewability)도 좋음 → RPM 최대. 템플릿화가 쉬움. 글리프 타일로 사진 문제 해결.
- 단점: **기억에 남지 않음** — 일본 포털이 다 이렇게 생김. SNS에 공유된 캡처만 보고 브랜드를 알아보기 어려움. 명조 리드 제목은 작은 화면에서 힘이 약함. 대만 독자에게는 "일본 사이트" 느낌이 강함.

**이 사업에 대한 장단점**
- 장점: 사이트 이름 "Brief"와 맞고, **AI 파이프라인이 이미 내는 구조(요약·FAQ·출처·숫자)가 그대로 화면 구조**가 되므로 매 기사 품질이 일정하고 만들기 쉬움. 출처 각주·AI 표기·수정 시각이 눈에 띄어 AdSense 품질 심사·검색 신뢰(E-E-A-T)에 유리. SNS로 들어온 모바일 독자가 첫 화면에서 바로 요점을 얻음. 일본 "まとめ", 대만 "懶人包" 습관에 둘 다 맞음. 번체 시안에서도 그대로 성립(일정판에 AAA 가오슝·워홀 마감 D-50).
- 단점: 팬덤 감성(설렘·화려함)은 가장 약함 — 건조해 보일 수 있음. 숫자가 없는 기사(인터뷰·화보형)는 숫자 칸을 비워야 하므로 대체 규칙이 필요. 랭킹 변동(▲4)은 분석 데이터가 있어야 의미가 있음(시안 값은 예시).

## 추천

**방향 3(BOARD)을 기본 골격으로, 방향 2의 포스터 체계를 SNS 공유 카드(OG 이미지)에만 빌려 쓰는 조합을 추천합니다.**

1. 유입의 대부분은 SNS → **기사 페이지** 착지입니다. 첫 화면에서 요점이 가장 빨리 전달되고, 광고가 본문을 밀어내지 않으면서도 4~5칸을 확보하는 게 방향 3입니다.
2. AI가 쓰는 사이트라는 약점을 **출처 각주·AI 표기·숫자 근거**로 신뢰 장치로 바꿉니다(AdSense 승인·유지에 직접 도움).
3. 브랜드 기억은 발차 안내판 + 플랩 로고로 확보하고, 공유 이미지는 방향 2 포스터(숫자 하나를 크게)로 만들면 피드에서 눈에 띕니다. 포스터는 OG 이미지 생성기 한 곳에만 있으면 되므로 유지 비용이 작습니다.
4. 일본(まとめ)·대만(懶人包) 둘 다에 같은 구조로 맞고, 번체 시안에서 줄바꿈·폰트 문제를 확인했습니다.

RPM을 최우선으로 한다면 방향 1이 대안입니다(광고 칸·목록 밀도 최대, 대신 브랜드 기억은 약함).
