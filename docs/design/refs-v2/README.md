## 1. 조사에서 알게 된 것

**대만 디자인 흐름 (2025~26)** — 단일 스타일이 아니라 **"social front door, editorial core"**: 입구는 피드처럼, 기사 페이지는 정돈되게. 중성 산세리프(Noto Sans TC·PingFang TC)로 본문, 포인트 제목에만 개성 있는 서체(粉圓 jf open huninn, 명조/세리프). 따뜻한 오프화이트 + 거의 검정 글자 + **강조색 하나**. 카드 모서리 12~24px, 그림자 거의 없음, 150~250ms 짧은 전환. ## 2. "일본은 아직도 다 구식 포털인가?" — 짧은 답

**아니요. 구식인 건 '뉴스 포털/연예 집계 사이트'이고, 여성 잡지 계열은 이미 모던합니다.**
- 구식 포털 계열: Kstyle·modelpress(v1 레퍼런스), Yahoo, ETtoday 같은 대만 포털도 같은 문법(광고 위주 첫 화면, 썸네일+3줄 제목 목록).
- 모던한 일본 사이트: **NYLON JAPAN**(핫핑크 워드마크, 2열 이미지 카드, 색 라벨 블록), **ViVi**(큰 원컷 히어로, 도트 인디케이터, "홈 화면에 추가" 안내 = PWA 유도), **CanCam**(잡지 표지 캐러셀, 2열 카드, NEW 배지), **Numero TOKYO**(작은 워드마크, 풀블리드 히어로).
- 다만 일본도 구조는 **밀도가 높은 편**이라(카테고리·랭킹·쇼핑 모듈 많음), 우리가 가져올 건 **이미지 카드·색 라벨·큰 히어로**이지 정보 밀도가 아닙니다. 그리고 젊은 층은 어느 나라든 매체 사이트보다 X·Instagram·TikTok·Weverse에서 시작하므로 비교 기준이 "앱 같은 화면"입니다.

### 클러스터 A. 소셜 네이티브 피드 — "앱처럼 열리는 사이트"

- **레퍼런스:** 小紅書(`xiaohongshu-appstore`), Threads(`threads-mobile`, `threads-appstore`), Instagram(`instagram-mobile`), Pinterest(`pinterest-appstore`), LINE WEBTOON(`webtoons-tw-mobile`), Weverse 앱(`weverse-appstore`)
- **시각 특징**
  - 레이아웃: 小紅書 **2열 폭포수(masonry) 카드**, 카드 = 커버 이미지 + 제목 2줄 + 작성자·하트수. Threads는 **한 열 텍스트 중심 피드**(아바타·시각·본문 → 이미지 → 하트/댓글/리포스트/공유 4버튼). Instagram 프로필은 3열 정사각 격자. WEBTOON은 3열 커버 + 큰 순위 숫자 겹침.
  - 이미지: 小紅書 커버는 **사진 위에 굵은 글자 크게**("更好玩呢?"), 텍스트 전용 커버 템플릿도 공식 제공(격자 노트 배경에 굵은 글자, 형광펜 밑줄). Pinterest 스토어 이미지는 **파스텔 그라데이션 배경 + 오려낸 꽃·나비 스티커 + 큰 번체 제목**, 영상 위에는 **노란 형광펜 띠 자막**("秋季家具令人心曠神怡")을 얹음. 피드는 높이가 제각각인 2열 폭포수.
  - 서체: 시스템 폰트(SF / PingFang). 제목은 중간~굵은 고딕, 메타(하트수·시각)는 작고 연한 회색. 커버 글자는 두꺼운 고딕.
  - 색: 흰 바탕 + **강조색 하나**(小紅書 빨강, WEBTOON 초록). 카드 모서리 8~12px.
  - 상호작용: 하단 탭바 5개(小紅書 `首頁 / 市集 / + / 訊息 / 我`, Threads는 홈·검색·+·♡·프로필), 가운데 + 버튼, 위로 당겨 새로고침, 무한 스크롤, 가로 칩 레일, 하트·저장 마이크로 애니메이션.
- **대만 젊은 여성이 좋아하는 이유:** IG·Threads·小紅書로 이미 훈련된 문법이라 학습 비용이 0이고, "저장해 두고 나중에 쓰는 정보(懶人包·同款·행사 정리)"를 바로 얻을 수 있음. 광고가 아닌 **친구가 정리해 준 느낌**.
- **iPhone 관점:** 엄지 영역에 하단 탭바 + 가운데 액션이 있어 한 손 조작에 최적. 탭바는 `env(safe-area-inset-bottom)`을 반영해야 홈 인디케이터와 안 겹침(Threads 캡처의 하단 바가 반투명 블러). 필터·언어 선택은 iOS 스타일 **바텀 시트**가 어울림. 다크모드는 `prefers-color-scheme`로 자동.
- **이미지가 없을 때:** 가장 강한 클러스터. **텍스트 전용 커버(굵은 글자 + 격자/단색 배경 + 스티커)**가 기본 카드 형태 그 자체라, 사진이 없어도 "같은 카드"로 보임. 공식 SNS 임베드는 Threads 스타일 한 열 카드에 그대로 맞음.
- **위험:** 카드가 단순 모방으로 보이면 "小紅書 짝퉁" 인상. 하트수 같은 소셜 지표는 우리에겐 없음(→ 조회순·저장 수 대신 에디터 지표). 小紅書는 대만에서 막혀 있어 링크·언급은 금지.

- **시각 특징**
  - **PopDaily:** 라벤더 상단 띠("開啟IG") + 연보라 필 칩 내비(`妝漂亮 波波雙購節 生活 發胖 打卡 穿搭 泡菜…`) + 큰 캐러셀 카드(화살표·도트) + `編輯精選 / 創作者精選` 알약 탭. 파스텔 보라/핑크, 둥근 요소.
  - **女人迷:** 큰 이미지 헤더 + 필기체 라틴("Feature now") + **노트 종이 위 손글씨 일러스트 카드**. 부드럽고 자기계발·공감 톤.
  - **Bella儂儂:** 거대한 굵은 워드마크, 큰 화보 이미지에 손글씨·말풍선 라벨을 덧붙임(IG 카드뉴스풍).
  - **VERSE / La Vie:** 문화지 쪽. VERSE는 **명조(세리프) 번체 제목 + 얇은 이중 괘선 + 호수 표기 + 달 아이콘 다크모드**, 가로로 넘기는 이미지 카드. La Vie는 굵은 워드마크와 공지 일러스트. 報導者는 **하단 탭바 5개**(首頁/最新/深度專題/我的閱讀/選單)와 세리프 대제목.
  - Cosmopolitan·ELLE·Vogue TW: 큰 사진 + **굵은 번체 제목 + 검정 바 내비**. 모바일 첫 화면은 광고가 먼저 나오는 경우가 많음(피할 점).
  - 서체: 번체는 **PingFang TC**(iOS 기본) 굵게. 손글씨·필기체·명조를 **장식 포인트**로만 사용.
- **대만 젊은 여성이 좋아하는 이유:** 대만 로컬 정서(귀엽고 부드러운 톤, 懶人包·星座·穿搭·韓星 같은 주제), 친구 말투 제목, IG용 카드 형식이 익숙함.
- **iPhone 관점:** 필 칩 가로 레일은 엄지로 스와이프하기 좋음. 둥근 알약 버튼은 iOS 컨트롤과 어울림. 報導者의 하단 탭바가 이 클러스터에서 유일하게 iOS 앱 같은 내비.
- **이미지가 없을 때:** 중간 이상. 女人迷의 **손글씨/노트 일러스트 카드**, PopDaily의 **파스텔 컬러 블록 + 스티커**는 사진 없이 성립하는 장식 언어. 폴백 카드 후보로 좋음.
- **위험:** 너무 귀여우면 "10대 취향"으로 한정됨. 파스텔 보라가 PopDaily 자체 시그니처라 그대로 쓰면 모방 인상. 일부 사이트(Cosmo·ELLE)는 광고가 압도해 "촘촘한 포털"로 되돌아갈 수 있음.

### 피해야 할 안티 레퍼런스

`koreastardaily-mobile`(KSD 韓星網: 틸 헤더 + 리드 1장 + 곧바로 영상 광고), `ettoday-star-mobile`(전면 광고 + 붉은 헤더 + 썸네일 목록), `line-today-mobile`(및 파일에는 넣지 않은 Yahoo 奇摩 娛樂)은 **정보는 많지만 첫 화면이 광고·목록 위주인 포털 문법**입니다. 대만 사용자가 K엔터 소식을 얻는 실제 경쟁자이지만, 오너가 "구식"이라 느끼는 화면이 바로 이쪽입니다. `numero-tokyo`처럼 큰 사진 + 목록 구성은 허용하되 광고가 첫 화면을 차지하는 구성은 피합니다.

## 4. 추천 (프로젝트에 맞게)

**A(피드 문법) + B(Weverse Magazine식 히어로·탭)를 뼈대로, D의 파스텔·손글씨를 스티커/폴백 카드에만 얹는 조합을 추천합니다. C는 큰 타이포 헤드라인 처리에만 참고.**

1. **독자 맞춤:** 10~30대 여성 팬덤, iPhone 중심 → A·B가 모두 "엄지 영역 하단 탭바 + 풀폭 사진/카드 + 가로 스와이프"를 공유함.
2. **이미지 정책:** 공식 배포 이미지(티저·컨셉 포토·포스터·드라마 스틸)와 공식 SNS 임베드를 쓸 수 있으므로 B의 큰 히어로가 가능. 사진이 부족한 기사는 A의 **텍스트 전용 커버**(굵은 글자 + 컬러/격자 배경 + 스티커)나 D의 **손글씨 노트 카드**로 같은 크기 카드로 이어 붙임.
3. **다국어:** 제목을 이미지에 합성하는 방식은 언어별로 다시 만들어야 하므로, 텍스트는 HTML로 두고 이미지는 어둡게 깔고 글자를 올리는 B 방식이 안전.
4. **v1과의 차이:** v1은 촘촘한 포털·신문형이라 보이는 정보량이 과했음. 이번 조합은 첫 화면에 **히어로 1 + 탭 + 2열 카드**만 두고, 랭킹·일정은 가로 레일로 접음.

### iPhone 구현 체크 (클러스터 공통)
- 하단 탭바 4~5개 + 가운데 액션(검색/저장), `viewport-fit=cover` + `env(safe-area-inset-*)`, 바텀 시트(필터·언어), 반투명 블러 바(i-D, Threads 참고).
- 시스템 서체 우선(SF Pro / PingFang TC / Hiragino Sans), 디스플레이만 라틴 서브셋 웹폰트. 번체·일본어는 `PingFang TC` / `Hiragino`로 용량 0.
- 다크모드 `prefers-color-scheme` 기본 지원(Berriz·Weverse가 팬 앱에서 보여주듯 사진·라이브 화면은 다크가 사진을 살림).
- 가로 스와이프(히어로·탭·칩)는 `scroll-snap`, 홈 화면에 추가(PWA) 안내는 ViVi 참고.
