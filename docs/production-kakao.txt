[웹 글·숏폼 제작이랑 질문 품질 체크 정리]

✅ 개발세팅 끝
- 웹: Next.js 16, 영/일/대만/한 4개 언어 페이지 뜸
- DB: Postgres + Prisma
- 수집기 2개 돌아감: 네이버 연예 랭킹 30개, 네이트판 50개 (제목·조회·댓글수)

🧹 질문 품질 체크 (니가 말한 거)
1단계 규칙: 중복, 사망·범죄·정치 같은 금지주제, 광고, 반응 약한 글, 질문 아닌 글 컷
2단계 AI 채점(Haiku): 해외관심도, 공식출처로 답할 수 있나, 시의성, 에버그린, 위험등급 → 점수
  → "공식출처로 답 가능" 점수 낮으면 버림 = 할루시 방지
3단계 사람: 하루 상위 20개 👍/👎, 처음 2주는 AI 점수랑 실제 조회수 비교해서 기준 맞춤

📝 웹 글
- 사실만 뽑기 → Sonnet이 포맷별로 작성 (이슈/반응/Q&A/가이드/리스트)
- 글마다 3줄요약 + 외국인이라면 + FAQ 3개
- 숫자는 출처에서 뽑은 값만 → 다르면 자동 삭제
- 현지화: 일본어 팬덤 용어, 통화 환산
- 하루 15주제 × 3개 언어 = 45페이지

🎬 숏폼 (Remotion 템플릿 4개)
1) 3줄 뉴스카드 20~30초
2) 랭킹 TOP5 30~45초
3) Q&A 3단계 45~70초 (틱톡 수익화용 1분+)
4) 네티즌 반응 말풍선 30~45초
순서: 대본 → 언어별 TTS + 자막싱크 → 카드/직접촬영/AI일러스트 → 렌더 → 플랫폼별 업로드
하루 3~5주제 × 3개 언어 = 영상 9~15개
유튜브 비진정성 정책 때문에 템플릿·목소리 돌려쓰고 직접 찍은 거 20% 섞음

🐦 트위터
니 말대로 제일 빠름. 근데 API가 글 1개 읽을 때마다 $0.005라 넓게 검색하면 월 50만원 넘음
→ 소속사·티켓사·시상식 공식계정 50개 + 키워드 20개 급상승만 보면 월 $50~100 상한으로 가능

👥 역할
너: 수집→품질체크→작성→숏폼→업로드 파이프라인, 프롬프트·템플릿
나: 웹·어드민(승인화면)·직접촬영·계정/키
