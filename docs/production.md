## ① 수집 품질 체크 (질문·이슈 걸러내기)

수집한 Signal을 3단계로 거른다. 결과는 `Signal.qualityScore`, `qualityNote`, `checkedAt`에 저장한다. 이 칸은 스키마에 이미 있다.

### 1단계 — 규칙 필터 (무료, 즉시)

| 걸러내는 것 | 방법 |
|---|---|
| 중복 | 같은 글 번호. 제목 유사도 0.8 이상이면 같은 주제로 묶는다 |
| 🔴 주제 | 키워드 사전: 사망, 범죄 피해, 성범죄, 미성년 선정성, 정치 등 |
| 광고·도배 | 링크만 있는 글, 홍보 문구 |
| 반응이 약한 것 | 소스별 중앙값보다 조회·댓글 **증가 속도**가 낮은 글 |
| 질문이 아닌 것 (카페·헬로톡·知恵袋) | 질문 표지어가 없는 글. 표지어: ?, 언제, 어떻게, 얼마, 어디, 方法, 怎麼, how, when 등 |

### 2단계 — AI 채점 (Haiku, 배치, 하루 몇십 원)

글마다 아래 JSON을 받는다.

```json
{
  "foreignInterest": 4,
  "answerable": 5,
  "timeliness": 3,
  "evergreen": 2,
  "risk": "YELLOW",
  "duplicateOf": null,
  "category": "KPOP",
  "format": "QNA",
  "locales": ["ja", "zh-TW"],
  "reason": "MAMA 오사카 티켓 질문, 공식 공지로 답할 수 있음"
}
```

**항목 설명**

| 항목 | 의미 |
|---|---|
| `foreignInterest` | 해외 팬·외국인이 궁금해할 정도 (1~5) |
| `answerable` | 공식 출처로 사실 확인이 되는지 (1~5). **이게 낮으면 할루시네이션 위험** → 버린다 |
| `timeliness` | 지금 써야 하는지 (1~5) |
| `evergreen` | 오래 검색될 주제인지 (1~5) |
| `risk` | GREEN / YELLOW / RED |
| `locales` | 어느 언어권에 특히 먹힐지 |

**점수 계산**

```
점수 = 해외관심 × 2 + 답변가능 × 2 + max(시의성, 에버그린) + 반응 증가 보정
```

- 기준 점수 이상이고 RED가 아니면 Topic 큐에 올린다.

### 3단계 — 사람 확인 + 보정

- 어드민에 하루 상위 20개를 점수와 이유와 함께 보여준다.
- 👍/👎를 누르면 기록이 남는다.
- **처음 2주는 AI 점수와 실제 성과를 비교한다.** 성과는 웹 PV와 숏폼 조회수다. 비교 결과로 가중치와 프롬프트를 매주 고친다.

## ② 사실 수집

- 랭킹 글은 원문 기사 페이지를 한 번 읽는다. 사람·날짜·장소·숫자·인용만 뽑아 `Article.facts`에 저장하고, 원문 문장은 저장하지 않는다.
- 일정·티켓 글은 소속사·티켓사·공식 SNS 공지를 1순위 출처로 쓴다. 링크는 `SourceRef`에 저장한다.
- 반응형 글은 판·더쿠 상위 댓글 3~5개를 짧게 인용한다. 닉네임은 가린다.

## ③ 웹 글 작성 (Sonnet)

**입력**: 사실 목록 + 포맷 템플릿 + 필진 페르소나 + 카테고리별 "외국인이라면" 체크리스트

**출력 (JSON)**

| 필드 | 내용 |
|---|---|
| `title` | 검색형 제목. 예: "MAMA 2026 오사카 티켓·라인업·생중계 보는 법" |
| `summary` | 3줄 요약 |
| `body` | 마크다운 본문 |
| `faq` | 3개 |
| `usedFacts` | 본문에 쓴 숫자가 어느 사실에서 왔는지 |

**포맷별 본문 구성**

| 포맷 | 구성 |
|---|---|
| 이슈 | 무슨 일 → 배경(해외 팬이 모르는 맥락) → 앞으로 일정 → 외국인이라면 → FAQ |
| 반응 | 무슨 일 → 한국 반응 요약 → 대표 댓글 3~5개 → 해외 팬이 알아둘 포인트 |
| Q&A | 답 먼저 (날짜·장소·가격) → 단계별 방법 → 자주 막히는 곳 → FAQ |
| 가이드 | 체크리스트 → 단계 → 나라별 차이 (일본·대만·유럽) → 제휴 박스 자리 |
| 리스트 | TOP N + 각 항목 한 줄 이유 + 어디서 사나 |

**페르소나** (필진 컨셉, 'AI 필진'으로 표시)
- 도쿄 K-pop 덕후 에디터 (ja)
- 타이베이 워홀러 출신 에디터 (zh-TW)
- 서울 사는 외국인 에디터 (en)

## ④ 자동 검사
- 본문 숫자와 `facts`를 대조한다. 다르면 그 문장을 삭제하거나 재작성한다.
- 🔴 필터를 다시 건다.
- 원문 유사도를 본다.
- 링크가 살아 있는지, 글자 수와 FAQ 개수를 확인한다.

## ⑤ 현지화 (Haiku, 필요하면 ja만 Sonnet)
- 언어별 용어 사전을 쓴다. 예: 콘서트 → ja `ソウルコン`, 응원봉 → zh-TW `應援棒`.
- 통화를 환산한다 (JPY/TWD/USD).
- 언어별 제휴 박스를 넣고 slug를 만든다.
- 번역 품질 점수가 낮으면 `indexable=false`로 둔다.

**하루 처리량 목표**: 15주제 × 3개 언어 = 45페이지

## ⑥ 숏폼 제작

### 템플릿 4종 (Remotion, 1080×1920)

| 템플릿 | 길이 | 화면 | 쓰는 곳 |
|---|---|---|---|
| **3줄 뉴스 카드** | 20~30초 | 큰 자막 카드 3장 + 출처 표기 | 컴백, 시상식 라인업 |
| **랭킹 TOP5** | 30~45초 | 5위 → 1위 카운트다운, 직접 찍은 제품 사진 | 편의점, 불닭, 명소 |
| **Q&A 3단계** | 45~70초 | 질문 → 단계 1·2·3 → 요약. **TikTok 수익화용으로 1분 이상** | 티켓팅, 워홀, eSIM |
| **네티즌 반응** | 30~45초 | 상황 카드 → 댓글 말풍선 애니메이션 | 이슈 반응 |

### 제작 순서 (1주제 → 3개 언어 → 영상 3개)

1. **대본 (Sonnet)**: 첫 2초 훅, 3~5개 장면, 마지막 CTA("자세한 건 프로필 링크"). JSON으로 받는다.
2. **음성**: 언어별 TTS (ja / en / zh-TW 목소리 각 2~3개를 돌려 쓴다). 단어별 타이밍을 받아 자막 싱크에 쓴다.
3. **화면 소스** (우선순위 순)
   - ① 텍스트 카드
   - ② 직접 찍은 소스 (성준: 편의점 신상, 거리, 공연장 외관). **20% 이상 섞는다**
   - ③ AI 일러스트 (음식·풍경, 실존 인물은 쓰지 않는다)
   - ④ Unsplash, 공공누리
   - 아이돌은 사진 없이 이름·날짜·장소 카드로만 만든다.
4. **배경음악**: 저작권 무료 음원 풀에서 돌려 쓴다.
5. **렌더**: 맥 또는 VPS에서 영상 1개당 1~3분 걸린다.
6. **업로드 큐**: 플랫폼·언어별 캡션과 해시태그, AI 표시 플래그를 붙인다.
   - YouTube, IG, Threads, FB → API
   - TikTok → 초안 업로드
   - 샤오홍슈 → 업로드 팩

**하루 목표**: 3~5주제 × 3개 언어 = 영상 9~15개 (동생 말대로 시간당 1편 이상 가능)

**품질·정책 장치**
- 템플릿을 매일 돌린다.
- 길이와 목소리를 바꿔 가며 쓴다.
- 직접 찍은 소스를 20% 이상 넣는다.
- 영상마다 대본이 다르다. 유튜브 "비진정성 콘텐츠" 대응이다.

**비용**: 영상 1개당 TTS 약 $0.01~0.05. 렌더는 Remotion이 3인 이하 팀 무료라 0원이다.

## ⑦ X(트위터) 수집 — 가장 빠른 소스

공식 API는 종량제다. 2026-10 기준 가격:
- 글 읽기 1개당 **$0.005**. 같은 글은 24시간 안에 다시 읽어도 1번만 과금된다.
- 키워드 언급량(Counts) 1회 요청당 $0.005
- 월 300만 건 읽기 상한이 있고, 콘솔에서 월 지출 상한을 걸 수 있다.

**넓게 검색하면 비싸다.** 예를 들어 1시간마다 100개씩 읽으면 월 약 $360이다. 그래서 좁게 쓴다.

| 방식 | 대상 | 월 비용 (예상) |
|---|---|---|
| **공식 계정 타임라인** | 소속사·아티스트·티켓사(NOL World 등)·시상식(MAMA·MMA·AAA)·방송사 공식 계정 50개 | 하루 새 글 약 300~500개 → **약 $45~75** |
| **키워드 급상승 감지** | 상위 아티스트·이슈 키워드 20개의 언급량(Counts)을 3시간마다 | **약 $24** |
| 합계 | **월 지출 상한 $50~100으로 시작** | |

- 공식 계정 공지가 뜨면 바로 Q&A·이슈 글 후보가 된다. 기사보다 빠르다.
- 로그인 계정으로 X를 긁는 방식은 쓰지 않는다. 차단과 계정 정지가 잦아서 API가 결과적으로 싸다.
