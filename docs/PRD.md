## 0. 결론 (먼저 읽을 것)

1. **우리는 연예 뉴스 사이트가 아니라 "외국인이 찾는 한국 정보" 사이트다.** 지금 글 111편 중 110편이 연예다. 연예 뉴스 시장은 이미 습관 독자를 가진 큰 사이트가 차지했다 (allkpop·Pannchoa 직접 방문 74~75%). 신규 사이트가 이길 수 있는 곳은 **검색으로 들어오는 사실·가이드 페이지**다 (kprofiles 검색 유입 78%, Creatrip 64%).
2. **돈과 사람이 같이 있는 곳은 K-쇼핑이다.** 올리브영·화장품·피부과, 불닭·라면·편의점 신상. 대만에서 'olive young' 검색이 '韓國旅遊'(한국 여행)의 3배, 홍콩은 7.8배다. 미국은 화장품 수출 1위 시장이고, 올리브영 글로벌 제휴는 13%다.
3. **같은 방문자라도 나라에 따라 돈이 수십 배 다르다.** 방문자 1,000명당 매출(ESTIMATE): 미국 $4.7, 일본 $3.0, 프랑스 $2.5, 대만 $1.1, 베트남 $0.15, 러시아 약 $0. **공연여행·생활 가이드는 연예 뉴스의 5~12배**다.
4. **역할을 나눈다.** 연예 = 사람을 데려오는 입구(SNS·디스커버). 사실 페이지(일정·아이돌·랭킹) = 검색 유입. 가이드(쇼핑·여행·유학·비자) = 돈. 모든 연예 글 아래에 돈 되는 다음 글을 자동으로 붙인다.
5. **수집은 robots.txt 를 지키는 소스로 옮긴다.** 지금 쓰는 네이버 연예 랭킹·네이트판은 robots.txt 가 수집을 막는다. 구글 트렌드 RSS·연합뉴스 RSS·더쿠 HOT·야후 지혜袋·블라인드·PTT·공식 공지로 바꾼다 (모두 확인함).
6. **AI 는 글쓰기·번역에만 쓴다.** 수집·분류·검사·일정·프로필·랭킹은 코드로 만든다. AI 누적 비용은 지금 약 2,500원이다 (상한 10만 원).

## 1. 목표와 지표

**북극성 지표: 월 매출** (광고 + 제휴 + 협찬). 그 앞에 아래 지표를 매주 본다.

| 지표 | 왜 | 어디서 |
|---|---|---|
| 검색 클릭 (언어 × 카테고리) | 신규 사이트의 주 유입 | Search Console |
| 1,000 방문당 매출 (EPMV, 언어 × 글 유형) | 어디에 글을 더 쓸지 정하는 기준 | 애널리틱스 + 제휴 리포트 |
| 페이지/방문 | 몰입. Pannchoa 6.2, 케이아지트 1.7 | 애널리틱스 |
| 재방문 (설치·푸시·뉴스레터 구독) | 검색 유입이 줄어도 남는 독자 | 자체 집계 |

**90일 목표 (2027-01-13까지, 목표값이지 예측이 아니다)**
- 색인된 페이지 1,500개 이상 (사실 페이지 + 가이드 + 번역)
- 검색 클릭 월 2만, 월 PV 5만
- 제휴 첫 매출, 애드센스 승인
- 홈 화면 설치·푸시 구독 1,000명

**8주 검증 루프**: 매주 언어 × 카테고리 칸별 검색 클릭과 EPMV 를 본다. 4주 뒤부터 상위 3칸에 생산량의 60%를 몰고, 하위 절반은 줄인다.

## 2. 시장 — 누가, 어디서, 무엇을 찾나

### 2.1 가장 큰 기회 (주제 × 시장)

점수 = 수요 × 돈 × 진입 쉬움 (각 1~5, ESTIMATE). 근거는 구글 트렌드(2025-10~2026-10)와 공식 통계.

| 순위 | 주제 | 시장 | 근거 |
|---|---|---|---|
| 1 | 올리브영 쇼핑·피부과 + 여행 동선 | 대만·홍콩 (zh-TW) | 'olive young' 검색 = 여행 검색의 3.0배(TW)·7.8배(HK). 대만 방한객 2026년 1~8월 165.6만, +32.2% (주요 시장 중 증가율 1위) |
| 2 | 지금 한국에서 뜨는 것: K-푸드 신상·신오쿠보·화장품 | 일본 (ja) | 韓国料理 검색 = 韓国ドラマ의 62%, 新大久保 = 韓国旅行의 2.7배. 일본인 의료관광 60만 명(2025) — 단 피부과는 구글이 아니라 SNS 로 움직인다 |
| 3 | K-푸드 제품(불닭·라면·편의점) 가이드·랭킹 | 영어 (미국·필리핀·싱가포르) | 미국 'buldak' = 'korea travel'의 2.6배. 라면 수출 15.2억 달러(+21.9%). 영어 광고 단가 최고 |
| 4 | K-뷰티 구매·성분 가이드 | 영어 (미국·싱가포르) | 미국 화장품 수출 21.9억 달러(1위). 경쟁이 세서 롱테일로 들어간다 |
| 5 | 한국 네티즌 반응 번역 (연예) | 영어 (+일본어) | 검색량은 1위. Pannchoa 월 480만 방문·페이지/방문 6.2. 돈보다 유입용 |
| 6 | 한국어 공부·유학·비자 | 베트남 (vi) | 베트남 유학생 107,807명 (1위, 법무부 2025-08). 'học tiếng hàn' 검색 = 여행 검색의 2.1배. 광고 단가는 낮아 유학원·어학당 연결로 번다 |
| 7 | 비자·K-ETA·입국 (목록 밖의 숨은 수요) | 필리핀·인니·베트남·태국 | 'korea visa' = 'korea travel'의 2.5배(PH), 9.8배(ID). K-ETA 면제가 2026-12-31 에 끝난다 |

### 2.2 가설 확인 결과 (사장님 가설 vs 데이터)

| 가설 | 결과 | 어떻게 반영하나 |
|---|---|---|
| K-pop 아이돌이 제일 인기 | **맞다** (검색 1위, 한국 연상 이미지 1위 17.5%). 하지만 신규 사이트는 이기기 어렵다 | 유입용. 일정·프로필 같은 사실 페이지로 검색을 잡는다 |
| 한국 음식 | **맞다** (해외한류실태조사 분야별 인기 1위 55.1%) | 제품·신상·랭킹 중심 (레시피·맛집은 강자가 있다) |
| 한국 화장품 | **맞다, 돈이 가장 된다** | 1급 섹션으로 올린다 |
| 한국 유학 | **베트남·우즈벡 등에서 맞다** | vi 의 중심. 리드 수익 |
| 국제결혼 | **커뮤니티 화제로는 강하지만 구글 검색은 거의 0** (일본·대만·베트남 모두). 중개 광고는 법으로 금지 | 연애·결혼 글은 SNS·공유용 화제 글과 비자·서류 가이드로만. 수익을 붙이지 않는다 |

### 2.3 지원하지 않는 언어 중 기회
- **스페인어**: K-pop 검색 비중 세계 1위가 멕시코, 한류 팬 2,780만, 스페인어 위키 K-pop 조회가 영어 다음 2위. 광고 단가는 낮다.
- **태국어**: 한류 팬 1,950만, 뷰티 경험률 1위.
- 1차 칸들이 검증된 뒤(8주) 추가를 결정한다.

## 4. 무엇을 만드나

### 4.1 섹션 구조

사용자에게 보이는 섹션은 5개로 묶는다. DB 카테고리는 지금 것을 그대로 쓴다.

| 섹션 | DB 카테고리 | 역할 |
|---|---|---|
| 엔터 | KPOP · KENT(셀럽) · KDRAMA | 유입 |
| K-쇼핑 | KBEAUTY · KFOOD | 검색 + 제휴 (돈) |
| 여행 | TRAVEL (입국·K-ETA·결제·교통·축제 포함) | 검색 + 제휴 (돈) |
| 한국어·유학 | STUDY | 검색 + 리드 (vi 중심) |
| 한국 생활 | LOVE(연애·결혼) · WORKING_HOLIDAY · JOBS · HOUSING · LIFE | 화제 + 검색 |

### 4.2 페이지 유형

| 유형 | 예 | 데이터 | AI 사용 | 우선순위 |
|---|---|---|---|---|
| **이벤트 페이지** `/[locale]/schedule/[id]` | MAMA 오사카: 날짜·장소·라인업·시청·예매·캘린더 추가·관련 글 | `upcoming.ts` (확인된 사실만) | 없음 | P0 |
| **아이돌 프로필** `/[locale]/idol/[slug]` | 그룹·멤버, 생일, 데뷔, 소속사, 최근 컴백, 관련 글 | 위키데이터 인물 사전 (이미 있음) | 없음 | P0 |
| **주간 랭킹** | 이번 주 올리브영 랭킹, 편의점 신상, 라면 신상 | 크롤러 (GS25·CU 허용 확인, 올리브영은 확인 필요) | 짧은 설명만 | P0 |
| **가이드 (Q&A)** | K-ETA 2026 총정리, 한국 여행 결제법, 전세 보증금 지키기, 축의금 얼마 | 공식 페이지 사실 목록 + 커뮤니티 질문 | 작성 1회 + 배치 번역 | P0 |
| **반응 번역** | "한국 네티즌은 이렇게 말한다" | 더쿠 HOT·블라인드 | 요약 작성 (개별 댓글 번역 인용은 1~2개 이하) | P1 |
| **뉴스 브리프** | 지금의 연예 기사 | 구글 트렌드 + 연합뉴스 RSS | 작성 1회 | P1 (생산량 30% 이하로) |

**모든 글의 끝**: 관련 글(같은 인물·카테고리), 인기 글, **돈 되는 다음 글 1개** (컴백·공연 → 공연여행 가이드, 아이돌 메이크업 → 올리브영 구매 가이드).

### 4.3 시리즈 (매주 고정)
1. 이번 주 올리브영 랭킹 (zh-TW · ja · en)
2. 편의점·라면 신상 (ja · en · zh-TW)
3. 한국 네티즌 반응 주간판 (en · ja)
4. 시상식 시즌 투표·시청 가이드 (MAMA·MMA·AAA·골든디스크 — 언어별 1편)

### 4.4 언어 전략

| 등급 | 언어 | 무엇을 | 색인 |
|---|---|---|---|
| 1차 | en · ja · zh-TW | 전부 | 전부 |
| 2차 | vi · id | vi: 한국어·유학·비자·생활 / id: K-pop 반응·K-쇼핑 | 가이드·사실 페이지만 |
| 유지 | ko · zh-CN | ko: 원문 겸 국내 검색 / zh-CN: OpenCC 변환, 샤오홍슈 인지도용 | 가이드만 |
| 축소 | fr · ru | fr: 자동 번역 유지 / ru: 연예 뉴스 중단(구글 광고가 러시아에서 멈춤), CIS 유학생·근로자 가이드만 | 가이드만 |

- 구글 스팸 정책의 'scaled content abuse'(AI 대량 생성·자동 번역)를 피하려고, **현지 정보가 없는 자동 번역 연예 글은 2차 이하 언어에서 noindex** 로 둔다 (`Translation.indexable`).
- 2차 이하 언어의 가이드에는 그 나라 정보를 넣는다: 비자 조건, 자국 대사관, 결제 수단, 통화.

## 5. 수집 — 무엇을 어디서

**원칙**: robots.txt 와 약관을 지킨다. 로그인·위장 수집은 하지 않는다. 커뮤니티는 "무엇을 쓸지"만 정하고, 숫자·날짜·요금·법은 공식 페이지에서 가져온다.

| 목적 | 소스 | 방법 | robots.txt (2026-10-16 확인) |
|---|---|---|---|
| 지금 뜨는 것 | 구글 트렌드 한국 일간 RSS | RSS, 1시간 | 허용 |
| 뉴스 사실 | 연합뉴스 RSS (+ 언론사 RSS) | RSS → 원문 페이지 | 허용 |
| 한국 반응 | 더쿠 HOT·스퀘어·드영배·예능, 블라인드 토픽 | 더쿠: 목록 HTML(제목·숫자·시각)과 쓰는 글의 댓글 1쪽, 1시간. 해외 IP 403 이면 서울 릴레이 | 허용 (더쿠 Content-Signal: ai-train=no, use=reference) |
| 외국인 질문 | 야후 지혜袋 (일본), PTT Korea_Travel (대만) | HTML, 1~6시간 | 허용 / robots 없음 |
| 쇼핑 랭킹 | GS25·CU 신상, 올리브영 | HTML, 하루 1번 | GS25 허용, CU robots 없음, 올리브영은 robots.txt 를 막아 둠 → 직접 제휴 신청 뒤 피드·문의로 |
| 바뀌는 사실 | K-ETA·하이코리아·스터디인코리아·문체부 축제 공지 | 하루 1번 목록 비교 | 허용 |
| 사람이 직접 (월 1회) | 네이버 카페, 스레드, 레딧 | 손으로 주제 씨앗만 | 자동 수집 금지 (robots·로그인 벽) |
| 사람이 직접 (하루 1번) | 디시인사이드(개념글), 인스티즈(이슈) | `worker seed-topic "<제목>" --source dc\|instiz` 로 제목만 | **자동 수집 금지** — 디시는 robots 허용이지만 약관 16조①이 크롤링을 막는다(서면 제휴 전까지). 인스티즈는 robots.txt 까지 Cloudflare 확인 화면 |
| **중단** | 네이버 연예 랭킹, 네이트판, 네이버 검색 | 쓰지 않는다. 네이버 연예·뉴스와 네이트판은 코드로 막음 (`collectors/policy.ts`) | **금지** |

**수집기 신분**: `HallyuBriefBot/1.0 (+사이트/en/about#bot)` 로 밝히고 요청한다(브라우저 위장 UA 금지). robots.txt 가 401·403·Cloudflare 확인 화면이면 전부 금지로 본다(404·410 만 허용). 약관이 막는 호스트(디시·인스티즈·네이트판·네이버 뉴스·벅스·지니·올리브영)는 robots 가 허용해도 요청하지 않는다(`collectors/policy.ts`). 더쿠가 해외 데이터센터 IP 에 403 을 내면 20초 뒤 한 번 더, 그래도 막히면 서울(icn1) 릴레이로 보낸다(`infra/collector-relay`, 더쿠 목록·댓글 주소만 허용). 다 막히면 실패가 아닌 '건너뜀'으로 남긴다. 유료 주거용 프록시·IP 바꿔 가며 접속하기는 하지 않는다.

**커뮤니티 규칙** (더쿠·사람 씨앗 공통)
1. 제목·글 번호·숫자(조회·댓글)·시각만 저장한다.
2. 본문·이미지·캡처는 저장하지도, 다시 올리지도 않는다.
3. 반응은 바꿔 쓴 요약과 짧은 인용 2개 이하로만 쓴다 (닉네임 없이).
4. 원문 글로 링크한다.
5. 게시중단 요청(더쿠 /infringement, admin@theqoo.net 또는 우리 문의 메일)은 24시간 안에 처리한다.
6. AI 학습에 쓰지 않는다 (더쿠 Content-Signal ai-train=no). robots.txt 가 ai-input=no 면 원문을 AI 에 넘기지도 않는다.
7. 사실은 공식·언론 출처로만 쓴다. 커뮤니티 글(더쿠 '기사/뉴스' 포함)은 주제 신호와 반응 자료일 뿐이다.

**사실 목록(fact pack)**: 주제별 공식 URL 표를 두고, 글을 쓸 때 1~3개 페이지를 가져와 필요한 2~4천 자만 AI 에 넘긴다. AI 는 그 안의 숫자만 쓸 수 있다. 잘 바뀌는 사실(K-ETA 면제, F-6 소득 기준, 교통 요금, 택스리펀, 축제 날짜)은 "YYYY-MM-DD 기준"을 붙이고, 공지 페이지가 바뀌면 글을 다시 쓴다.

## 6. 생산 파이프라인과 비용

```
수집(코드) → 분류·점수(코드, heuristics.ts) → 사실 목록(코드) → 작성(Haiku 1회) → 검사(코드) → 발행 → 배치 번역(Haiku, 50% 할인) → 간체(OpenCC)
```

| 단계 | 방식 | 비용 |
|---|---|---|
| 수집·분류·점수·이미지·간체 | 코드 | 0원 |
| 이벤트·아이돌·랭킹 페이지 | 데이터 + 템플릿 | 0원 |
| 기사 작성 (en·ja·zh-TW·ko 한 번에) | Haiku 5.5 | 1편 약 4원 |
| vi·id·fr·ru 번역 | 배치 API | 1편 4개 언어 약 3원 |
| 발행 전 검사 | 코드: 숫자 대조, 언어 확인, **원문 문장 겹침(n-gram) 검사**(새로 만든다), 금지 주제 | 0원 |

- **월 비용 (ESTIMATE)**: 하루 30편이면 AI 약 6,300원/월. 누적 상한 10만 원은 코드가 막는다 (`budget.ts`, 진행 중 배치 포함).
- **사람 확인**: 애드센스는 "사람 검토 없는 자동 생성"을 막는다. 하루 10분, 가이드 글만 발행 전에 한 번 본다 (`AUTO_PUBLISH` 를 가이드에서만 끈다).

## 8. 성장 채널

### 8.1 검색 (1순위)
- 사실 페이지(일정·아이돌·랭킹)와 가이드를 서버에서 렌더링한다 (본문이 HTML 에 있어야 한다. Kpopmap 은 클라이언트 렌더링 앱으로 바꾼 뒤 방문이 급감했다).
- 구글 검색 유입은 매체 기준 1년에 −40%, AI 요약이 뜨면 1위 클릭률 −58% 다. **AI 가 대신 답하기 어려운 페이지**(날짜·순위·예매·투표 링크가 계속 바뀌는 페이지)에 집중한다.
- 디스커버 요건: `max-image-preview:large`, 글마다 1200px 이상 16:9 고유 이미지 (텍스트 카드 자동 생성), 공통 OG 이미지 금지. 'Preferred Sources' 버튼.

### 8.2 SNS (발견용) — 언어별 1순위가 다르다

| 언어 | 1순위 | 링크로 사이트 보내기 |
|---|---|---|
| ja | X, LINE 공유 | X 링크 글 |
| zh-TW | Threads, Facebook, LINE | Threads 링크 글 |
| en | X, Reddit(답변 위주, 자기 링크 10% 이하), Pinterest(뷰티·음식) | 모든 핀이 링크 |
| vi · id | Facebook, TikTok | 프로필 링크 |
| zh-CN | 샤오홍슈 (링크 불가, 인지도용) | — |

- **숏폼은 사이트 클릭을 거의 못 만든다** (릴스 캡션·쇼츠 설명 링크 불가). 발견용으로 쓰고, 클릭은 스토리 링크 스티커·Threads·X 로 거둔다.
- **인스타는 2026-04-30 부터 남의 콘텐츠를 다시 올리는 계정을 추천에서 뺀다.** 직캠·방송 클립 재업로드는 하지 않는다. 동생 숏폼 포맷 3종: ① 편의점·올리브영 신상 직접 촬영 ② 컴백·시상식 30초 정리(텍스트·공식 이미지·보이스오버) ③ 외국인 Q&A(티켓팅·비자·TOPIK).

### 8.3 재방문
1. **홈 화면 설치 + 웹푸시**: 안드로이드는 설치 버튼, 아이폰은 "공유 → 홈 화면에 추가" 안내 (아이폰 푸시는 설치 뒤에만 된다). 알림은 고른 것만: 최애 컴백 D-1, 생일, 투표 마감.
2. **주간 뉴스레터** (en · ja 먼저): 이번 주 일정 + 랭킹으로 자동 생성.
3. **공유 버튼**: LINE · WhatsApp · Messenger · X · Threads (메신저 공유가 PV 의 11%).
4. **팬덤 기능**: 컴백 D-day 캘린더(.ics 구독), 아이돌 생일 알림, 시상식 투표 가이드, 실시간 결과 페이지.
5. **댓글**: 이미 있다. 질문 댓글은 다음 글 후보로 보낸다.

## 9. 웹 제품 요구사항

### 9.1 화면 구조
- **헤더**: 왼쪽 로고, 오른쪽 언어 버튼 + 햄버거 메뉴 (기사에서는 공유 버튼 추가).
- **햄버거 메뉴**: 섹션 5개와 카테고리, 일정, 언어, 사이트 소개·편집 방침·개인정보처리방침·문의.
- **하단 탭 (3~4개)**: 홈 · 일정 · K-쇼핑(랭킹) · 가이드. 언어는 하단 탭에서 뺀다.
- **홈**: 지금 인기 글 → 다가오는 일정(큰 카드, 누르면 이벤트 페이지) → 섹션별 최신 → 피드.
- **기사**: 본문 → FAQ → 출처 → AI 표시 → 댓글 → 돈 되는 다음 글 → 관련 글 → 인기 글.

### 9.2 디자인 기준
- **기본기**는 토스·애플 원칙을 따른다: 글자 크기 체계, 8px 간격, 터치 영역 44px 이상, 화면마다 주된 행동 하나, 짧은 문구.
- **생김새**는 우리 것: 체리색 하나, 파스텔, 포토카드·티켓 모티프. 참고는 위버스·샤오홍슈·인스타그램 (토스의 금융 앱 느낌을 복제하지 않는다).
- **언어별 밀도**: 일본어 피드는 카드에 정보를 조금 더 보인다. 언어별 클릭률·스크롤로 확인한다.
- 세부 규격은 `docs/design-spec.md` (작성 중)에 둔다.

### 9.3 필수 페이지 (애드센스·법)
- 사이트 소개, 편집 방침(AI 보조 작성·사실 확인·출처 원칙·정정 방법), 개인정보처리방침(댓글 IP 해시 포함), 이용약관(삭제 요청·임시조치 절차), 문의 메일, 제휴 고지.

## 12. 하지 않는 것
- 연예 뉴스로 큰 사이트와 정면 승부
- 비밀번호 회원가입, 네이티브 앱 (PWA 로 충분)
  - 2026-10-20 검토(`docs/predeploy/login.md`): 지금은 로그인을 넣지 않는다(30일 방문자 51명, 가입 마찰 > 효과). 대신 아이폰 사파리의 '7일 지나면 기기 저장소 삭제'(ITP)로 저장함이 사라지는 문제가 진짜 위험이라 다음 단계에서 ① 저장할 때 서버가 심는 HttpOnly 기기 쿠키 + 서버 백업(비용 0, 동의 배너 불필요) ② 이메일 한 칸(매직 링크로 목록 백업·기기 옮기기·주간 소식) 순서로 붙인다. 소셜 로그인은 LINE(ja·zh-TW)만 나중 후보. 시술 항목은 어떤 신원과도 묶지 않는다
- robots.txt 를 어기는 수집, 로그인 계정·검색봇 위장 수집
- 남의 영상·사진 재업로드
- 국제결혼 중개·데이팅 제휴, 피부과 알선, 티켓 리셀
