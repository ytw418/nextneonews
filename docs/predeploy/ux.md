# 배포 전 점검 — 화면 사용성(UI/UX) (2026-10-19 밤)

- 방법: `http://localhost:3400`(dev 최신 빌드, 로컬 DB)을 Playwright **WebKit 아이폰 15**로 직접 눌러 봤다. 높이는 사파리에서 실제로 보이는 **390×664**를 기본으로 하고, DESIGN 기준인 390×844도 같이 쟀다. 데이터 절약 측정은 Chromium으로 했다(느린 4G 1.6Mbps·150ms, `Save-Data: on`).
- 근거: 캡처 101장은 `/tmp/ux-shots/`, 측정 스크립트는 `/tmp/ux-work/*.mjs`에 있다. 코드는 고치지 않았다.
- 한 줄 결론: 뼈대(탭 4개, 로그인 없는 저장, 제휴 고지, 다크 모드, 긴 라벨)는 배포해도 된다. 다만 **돈이 나오는 화면(제품 상세·뷰티 허브)이 '빈 색 상자 + 읽을 수 없는 가격'** 이라 클릭률을 깎는다. **모든 404가 영어 흰 화면**이라는 점도 문제다.
